# Security Policy

## Supported Versions

Only the latest version of this project is actively supported with security updates. (main branch)

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to Alberto Licea at [albertolicea00@icloud.com](mailto:albertolicea00@icloud.com). All security vulnerabilities will be promptly addressed.

Please do not open a public GitHub issue for security-related vulnerabilities.
